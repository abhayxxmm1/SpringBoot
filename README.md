# Spring Boot Practice Repository

## Overview

This repository contains Spring Boot practice projects focused on learning backend development concepts using:

- Spring Boot
- Spring MVC
- REST APIs
- JPA & Hibernate
- H2 Database
- Exception Handling
- ResponseEntity
- CRUD Operations

The repository includes beginner-to-intermediate level backend projects created to strengthen Java backend development skills and understand enterprise application architecture.
